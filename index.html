SmartDock

SmartDock is a docking library for WPF on .NET 8. A layout is a tree of splits and tab groups. Every pane has a stable content id, and when a layout is shown or restored, the dock maps each id back to your control.

There are two packages, both in the SmartDock namespace:

  • SmartDock is the WPF part. DockManager draws the splits, tabs, floating windows, auto-hide strips, and toolbars.
  • SmartDock.Core has the layout model, the edit operations, and the JSON serializer. It doesn't reference WPF, so a service or a command-line tool can build and save layouts too.

Features

  • Horizontal and vertical splits. Proportions are weights and do not have to sum to 1.
  • Document and tool tab groups. Only the selected tab's content is in the visual tree.
  • Dock a pane to the left, right, top, or bottom of an anchor, or add it as a tab.
  • Floating windows with their own captions. They can be maximized and docked back.
  • Auto-hide strips and flyouts for tool panes that allow it.
  • Drag a tab along its strip to reorder it, or off the strip to float it, then drop it on a dock guide.
  • Hide a pane and show it again later. A hidden pane stays in the saved layout.
  • Save and load the whole layout as compact JSON, including floats, auto-hide, hidden panes, and toolbars.
  • Toolbars on the main window and on panes, including a pane inside a floating window or an open auto-hide flyout, with a customize menu. Their positions are saved with the layout. They do not dock to the outside of a floating window.
  • A Ctrl+Tab pane switcher, plus commands for close, document cycling, float, and auto-hide.
  • Dark, light, and blue chrome. Dark is the default.
  • Events for layout changes, closing, pane state, activation, and when a pane's content is mounted or unmounted.
  • Bind documents and tools to a collection, with a data template per item.

Install

dotnet add package SmartDock --version 0.16.4

It pulls in SmartDock.Core. If you only build or store layouts, the core package is enough:

dotnet add package SmartDock.Core --version 0.16.4

The WPF package needs net8.0-windows. SmartDock.Core targets plain net8.0.
