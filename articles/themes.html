Themes

Set DockManager.Theme to DockThemeKind.Dark (the default), Light, or Blue. The new brushes replace the old ones in the manager, its floating windows, the guide overlay, the pane switcher, and the auto-hide flyout, and everything repaints in place. The theme is not saved with the layout.

public static void UseLight(DockManager dock)
{
    dock.Theme = DockThemeKind.Light;
}

To use the dock palette outside the manager, for example in a dictionary merged into Application.Resources, call DockTheme.Apply on any FrameworkElement or ResourceDictionary.

public static void ApplyBlue(FrameworkElement element)
{
    DockTheme.Apply(element, DockThemeKind.Blue);
}

The chrome looks brushes up by resource key, not through the static brush properties. The keys are Dock.Workspace, Dock.Panel, Dock.Chrome, Dock.Header, Dock.Border, Dock.Text, Dock.Muted, Dock.Accent, Dock.AccentSoft, Dock.Guide, Dock.GuideButton, Dock.GuideBorder, Dock.Hover, and Dock.Font. DockTheme exposes each name as a *Key constant, for example DockTheme.WorkspaceKey.

The static brushes on DockTheme always hold the dark palette, and the chrome doesn't use them. Don't reference DockTheme.Border or DockTheme.Panel with x:Static: those names match WPF types, and the markup compiler resolves them as types.

DockTheme.CreateScrollBarResources returns styles for the scroll bar, tool tip, and focus visual. The manager, each floating window, and the switcher merge it already. Merge your own copy if you want the same scroll bars elsewhere in the app.

DockTheme.CreateMenuResources returns menu, context menu, menu item, and separator styles in the dock colors. Nothing merges it for you. Merge it into application resources if your menus should match the dock, or leave it out to keep the system look. A copy merged into the host window follows Theme changes.
