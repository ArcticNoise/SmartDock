Saving and loading layouts

DockSerializer turns a layout into one line of compact JSON and back. The format version is DockLayout.CurrentVersion, currently 1.

Serialize validates the tree before writing. Deserialize throws DockLayoutException when the JSON is malformed or the tree fails validation. That covers a version other than 1, a missing or repeated id, a split with fewer than two children, an empty tab group that no hidden entry points to, and a non-finite number where a finite one is required.

A round trip is exact: a document written by Serialize reads back as an equal layout and writes out as the same bytes. The file keeps ids, weights, the selected tab, float bounds and the maximized flag, auto-hide entries, hidden panes, and toolbar state. When DockLayout.ToolBars is null, the file has no toolBars object at all. Enums are written as lowercase strings, and each node has "type": "split" or "type": "tabs".

public static string CoreRoundTrip(DockLayout layout)
{
    string json = DockSerializer.Serialize(layout);
    DockLayout restored = DockSerializer.Deserialize(json);
    return DockSerializer.Serialize(restored);
}

With a DockManager, use SaveLayout and LoadLayout. SaveLayout copies the current toolbar positions into the layout before it serializes, and throws InvalidOperationException when no layout is assigned. LoadLayout deserializes and assigns Layout. Call it before the window is shown, or while the manager is hidden, so the first frame on screen is the saved layout. Loading raises PaneStateChanged for panes whose state changed. It never raises PaneClosing or PaneClosed.

public static void ManagerRoundTrip(DockManager dock, string path)
{
    File.WriteAllText(path, dock.SaveLayout());
    dock.LoadLayout(File.ReadAllText(path));
}

DockSerializer.SerializeUtf8 writes the same document as UTF-8 bytes. DockLayout.Clone makes a deep copy through the same JSON and also copies DockPane.PreviousGroupId, which the file doesn't store.

The theme, the Ctrl+Tab activation order, and pane icons are not saved. Restore them yourself if you need them.
