Keyboard

Ctrl+Tab

Hold Ctrl and press Tab to open the pane switcher. It lists the visible panes, most recently activated first; hidden panes are left out and tools are marked "Tool". With fewer than two panes the key does nothing.

The host window and every floating window listen for the key, so it works even when focus is outside the panes. The popup opens over the window that got the key and stays there while you move through the list.

The first press highlights the previous pane. Tab or Down moves down the list, Shift+Tab or Up moves back, and the list wraps. Release Ctrl to activate the highlighted pane: its tab is selected, an auto-hidden pane's flyout opens, and a floating pane's window comes to the front. Escape closes the switcher without changing the active pane.

The activation order lives in memory only. It is not saved with the layout.

Commands

DockCommands has routed commands that DockManager already handles. Their default keys are in each command's InputGestures, which is read on every key press, so a change takes effect immediately.

Command Default key What it does
ClosePane Ctrl+F4 Closes the active pane. A pane with HideOnClose is hidden instead of removed.
NextDocument Ctrl+PageDown Activates the next document tab.
PreviousDocument Ctrl+PageUp Activates the previous document tab.
ToggleFloat none Floats the active pane, or docks a floating pane back.
ToggleAutoHide none Auto-hides the active tool, or pins a tool that is already on an auto-hide strip. 
public static void Run(DockManager dock)
{
    DockCommands.ClosePane.Execute(null, dock);
    DockCommands.NextDocument.Execute(null, dock);
    DockCommands.PreviousDocument.Execute(null, dock);
    DockCommands.ToggleFloat.Execute(null, dock);
    DockCommands.ToggleAutoHide.Execute(null, dock);
}

ToggleFloat opens the float at (80, 80), 480 by 360, if the pane is allowed to float, and docks a pane that is already floating back. ToggleAutoHide does nothing when the active pane can't auto-hide.

To rebind a command, replace its gestures:

public static void RebindClose()
{
    DockCommands.ClosePane.InputGestures.Clear();
    DockCommands.ClosePane.InputGestures.Add(new KeyGesture(Key.W, ModifierKeys.Control));
}

DockCommands is static, so this changes the key for every DockManager in the process.
