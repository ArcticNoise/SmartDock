Getting started

You need three things: a DockManager in a window, a factory for each content id, and a layout. The manager calls a factory the first time its pane is shown and keeps the control, so moving, floating, or reloading the pane reuses the same instance.

Register factories before you assign Layout. A pane shown without a factory gets a "Missing content: id" placeholder, and that placeholder stays cached while the pane is in the layout. The manager starts with no layout, so assign one before the window is shown, or the first frame is empty.

<Window x:Class="SmartDock.Docs.Samples.GettingStartedWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:dock="clr-namespace:SmartDock;assembly=SmartDock"
        Title="SmartDock"
        Height="640"
        Width="960">
  <dock:DockManager x:Name="Dock" />
</Window>

using System.Windows;
using System.Windows.Controls;

namespace SmartDock.Docs.Samples;

public partial class GettingStartedWindow : Window
{
    public GettingStartedWindow()
    {
        InitializeComponent();

        Dock.RegisterContent("solution", () => new TreeView());
        Dock.RegisterContent("program", () => new TextBox());
        Dock.RegisterContent("readme", () => new TextBox());

        Dock.Layout = DockTree.Create(DockTree.Split("root", SplitOrientation.Horizontal,
            DockTree.Weighted(0.25, DockTree.Tabs("tools", DockKind.Tool,
                DockTree.Tool("solution", "Solution Explorer", canClose: false))),
            DockTree.Weighted(0.75, DockTree.Tabs("docs", DockKind.Document,
                DockTree.Document("program", "Program.cs"),
                DockTree.Document("readme", "README.md")))));
    }
}

A horizontal DockTree.Split lays out its children left to right, a vertical one top to bottom. DockTree.Weighted gives a child its weight. DockTree.Tool creates a tool pane that can auto-hide; DockTree.Document creates a document pane that can't.

Content ids are case-sensitive and must be unique within a layout. Use the same string in the layout and in RegisterContent.

The WPF package pulls in SmartDock.Core. If a project only builds or stores layouts and never shows a window, reference SmartDock.Core alone and use DockTree and DockSerializer from there. Both packages use the SmartDock namespace.
