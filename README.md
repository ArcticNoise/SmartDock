# SmartDock

A docking library for WPF on .NET 8.

You describe the layout as a tree of splits and tab groups, register a factory for each pane's content id, and `DockManager` does the rest: tabs, floating windows, auto-hide strips, dock guides, toolbars, and saving the whole thing to JSON.

**Documentation:** <https://arcticnoise.github.io/SmartDock/>

This repository holds the documentation site and the issue tracker.

## Reporting a bug

Open an [issue](https://github.com/ArcticNoise/SmartDock/issues/new/choose). The most useful reports include the SmartDock version, Windows version and display scaling, and the smallest layout that shows the problem. A saved layout JSON or a short screen recording helps a lot.
