New window rect after dragging edge by (dx, dy). Only those edges move. A moved edge stops at min when the drag would shrink past it, and stops at screen when the drag would leave the virtual screen. An edge already outside that screen is not pulled back, so a zero delta leaves start unchanged. A zero-size screen does not clamp. The screen may start at a negative coordinate.
