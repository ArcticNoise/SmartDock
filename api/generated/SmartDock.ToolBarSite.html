One place a toolbar can dock. An empty PaneId and WindowId is the main window. A pane id is that pane's content. A window id is a floating window's id. A window with a larger ZOrder is painted above one with a smaller value. OwnerId is the window that shows a pane: empty for the main window, else a floating window's id. Cover is the open auto-hide flyout that shows this pane, caption included, painted above the other panes of that window. A point inside it selects this pane even when a smaller pane underneath contains the point. Bounds stays the pane's content, so the flyout's edges are where a docked pane's are. An empty cover is a pane that is not in a flyout.
