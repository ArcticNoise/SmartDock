Dock colors. The static brushes are the dark palette and stay the instances they have always been. Chrome, floats, guides, the switcher, and menus paint with resource keys, so Apply(FrameworkElement, DockThemeKind) can replace those brushes and open windows repaint. CreateMenuResources() is the opt-in menu and context menu. Nothing merges it on its own. CreateScrollBarResources() is the scrollbar, tooltip, and focus visual. The dock manager, each float, and the switcher merge it themselves. A host merges another copy for bars outside the dock.

CreateMenuResources()

A new copy of MenuResourcesUri plus the dock brushes under string keys. One dictionary instance can be merged into one owner. The XAML uses those keys because x:Static on Border or Panel is stored as a type id. A context menu is a separate tree. Merge the dictionary into Resources or into a window the menu's placement target can see.

CreateScrollBarResources()

Scroll bar and scroll viewer styles, plus the dock tooltip and focus visual. One dictionary instance can be merged into one owner. The manager, each float, the switcher, and the tab overflow menu each merge their own, so pane content is themed without a host having to ask. Merge another copy for scrollbars that live outside the dock. The returned dictionary is a copy of the XAML. It has no brush keys. Brushes stay on the owner, because writing into the shared source dictionary drops the implicit ScrollBar style.
