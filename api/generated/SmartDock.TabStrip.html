Fit(ReadOnlySpan<double>, int, double, double)

Which headers fit in stripWidth. Widths that are not positive are treated as zero. The selected tab is always in the result when the strip is not empty, including when the strip width is zero or that one header is wider than the strip. When every header fits, Overflow is false and the button width is not reserved. Otherwise the button is reserved and the visible run is the one that contains the selection and sits as far left as it can: headers before the selection are kept while they fit, then headers after it fill any leftover width. A selection already inside the left-aligned run stays there. A selection past that run moves to the nearest slot that brings it on screen.

Slot(IReadOnlyList<Header>, int, double)

Slot the dragged header should occupy, from 0 through the last header. headers are the strip in its current order, including the dragged header, in the same coordinates as pointerX. The pointer takes a neighbor's slot once it is past that header's midpoint. The midpoint itself belongs to the following gap, the same rule as InsertionIndex(IReadOnlyList<Header>, double).
