One snapped size of a floating toolbar. Columns and Rows place every button. Horizontal fills a row and then the next. Vertical fills a column and then the next. Width and Height are the window: the cells plus the chrome given to FitGrid(int, double, double, double, double, double, double, double, double, double, double, int), and at least that orientation's minimum width. Vertical is true when there are fewer Columns than Rows. A square grid is horizontal.
