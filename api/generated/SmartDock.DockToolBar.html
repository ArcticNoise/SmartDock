Attached properties for a ToolBar placed in ToolBars. A toolbar created from ToolBarsSource reads the same values from DockToolBarItem instead. KeyProperty identifies one button.

AlignmentProperty

Default end of the band. End pins the toolbar to the far end (right on a top or bottom band, bottom on a left or right band) until the user docks it somewhere else. The default is Start. Applied only while the toolbar has no place yet.

PaneIdProperty

Content id of the pane that owns this toolbar when it has no saved or current place. Empty means a window tray, on EdgeProperty. A pane that is not in the layout uses the main window's top tray instead. Applied only while the toolbar has no place yet.

public static readonly DependencyProperty PaneIdProperty

Field Value

DependencyProperty

ShowOverflowProperty

Identifies the ShowOverflow attached property. True gives the toolbar a share of the band's leftover length, so items that do not fit go behind the overflow chevron. False, the default, sizes it to its content.

public static readonly DependencyProperty ShowOverflowProperty
