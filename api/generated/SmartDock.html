Namespace SmartDock

Classes

AutoHideEntry

One auto-hidden pane, plus the size used when it is pinned back or shown as a flyout.

AutoHideLayout

Panes pinned to the four edges as auto-hide tabs.

AutoHideTargets

Picks an auto-hide edge while a tool pane is dragged. Documents and any float that is not tools-only are rejected by Allows(DockLayout, string?, string?) and get no target. A dock guide that contains the point wins, including a root-edge button that overlaps the hot zone. A floating window under the pointer wins as well, including where that window covers the zone: the drop stays a float dock, not an auto-hide. No allocations.

DockActivePaneEventArgs

The active pane changed. Either id is null when there was, or is, no active pane.

DockCaption

A caption bar the user drags. The default template paints the dock palette. A host replaces the look with an implicit Style or a new Template. Drag, double-click, and the window buttons stay on this control. A missing part is simply absent.

DockCommands

Commands a host can bind or rebind. Default keys live in InputGestures and are read when the key is pressed, so replacing a gesture takes effect on the next key. Close is Ctrl+F4. Next and previous document are Ctrl+PageDown and Ctrl+PageUp. Float, auto-hide, save layout, and load layout have no default key.

DockCompare

Structural equality for layouts. Doubles match exactly, which is what a JSON round-trip preserves.

DockContentRegistry

Factories for the controls a layout reconnects by content id. DockManager calls a factory when it has no cached element for that id and reuses the element when the pane moves, floats, or the layout is loaded again. Unregister(string) removes a factory so Register(string, Func<UIElement>) can install another.

DockCustomTheme

Base class for a host theme. Subclass it and return the System.Uri of a resource dictionary that holds Dock and DockMenu brush keys, such as Dock.Chrome and DockMenu.Panel. Assign an instance to CustomTheme. One dictionary can be shared by every window. The manager reads those keys from it and does not merge the dictionary.

DockDragSession

Deterministic drag gesture. The WPF control feeds coordinates; tests call Update(DockLayout, DragPointer) and End(DockLayout) with the same inputs and no mouse. A horizontal move inside the source strip moves the tab as soon as the pointer reaches a neighbor's midpoint. End(DockLayout) reports that reorder once. Leaving the strip floats the pane. A snapshot taken before the first change is what Cancel() restores. A tool drop on an auto-hide strip hides the dragged pane, or every pane when the gesture is moving a tool-only float. DragGroup() and MoveWindow(string) dock the whole window on a guide drop.

DockDropPreview

The landing rectangle drawn while a drag is over a guide or an auto-hide edge. The default template fills Dock.Guide and draws no border. A host replaces the look with an implicit Style or a new Template. The rectangle itself is chosen in SmartDock.Core. The template only paints that rectangle.

DockEdit

Mutates a DockLayout. Every successful structural edit leaves a layout that Validate(DockLayout) accepts. Empty groups are removed and single-child splits collapse, except an empty tab group that a hidden entry still names. That group stays, with its weight, as a restore anchor. Proportions are weights. A side dock gives the incoming pane the supplied proportion of the anchor's area.

DockGuideButton

One compass slot or root-edge button. The default template paints the dock palette. A host replaces the look with an implicit Style or a new Template. Hit testing stays on the guide rectangle in SmartDock.Core. The template paints inside this control.

DockGuides

Hit testing for dock guides. A compass is centered on the leaf under the pointer. Four buttons sit at the midpoints of the host edges and dock against the root. A point that is not on a button is not a target. The preview is a separate rect from Landing(DockRect, ReadOnlySpan<NodeBounds>, DropGuide), not the button. No allocations.

DockItem

Bindable pane properties for one item in DocumentsSource or ToolsSource. A Style assigned to DocumentItemStyle or ToolItemStyle targets this type. Its setters bind against the item, which is the DataContext. The manager reads these values when the item enters the source and again when they change. This element is not placed in the visual tree.

DockLayout

The whole dock: a main tree, floating windows, auto-hide bars, and hidden panes. The object is a plain tree. DockEdit mutates it, DockSerializer saves it, and the WPF DockManager turns it into controls. It is safe to build on any thread, and it is not safe to mutate from two threads at once.

DockLayoutException

Invalid layout data, or a layout JSON document this version cannot read. Editing methods return DockEditResult instead of throwing for ordinary refusals such as a missing pane or a disabled close.

DockManager

Hosts a DockLayout. Register content by id, assign Layout, and the control builds the splits, tabs, floating windows, and auto-hide bars. Only the selected tab's content is in the tree. Drag a tab along its strip to reorder it, or off the strip to float it, then drop it on a guide to dock it. A tool, or a float of tools, can also drop on an auto-hide strip. Guides and the landing preview are drawn in a topmost overlay so the dragged window cannot cover them. Another float under the pointer shows that float's compass and edge guides; the topmost one wins, and the dragged window is skipped. A dock guide or that float wins where it overlaps an auto-hide hot zone. Documents are not an auto-hide target. The same gesture is covered by the internal drag methods, which call DockDragSession with coordinates and no mouse. Ctrl+Tab switches panes. DockCommands closes, cycles document tabs, toggles float and auto-hide, and saves the layout. When AnimationsEnabled is set and Windows animations are on, reordered tab headers slide and the dock guides fade. The auto-hide flyout is a child window so it paints above an HwndHost pane. It opens and closes at its arranged size: a render transform does not move that HWND. Those clocks do not change layout, focus, or events. ResizeGripThickness is the hit zone of a splitter, a flyout edge, and a float's border. ResizeMode applies splitter, flyout, and floating-window sizes live, once per frame, or as a preview on release.

DockMru

Most-recently-activated pane order, and cycling of document tabs. Index 0 is the pane activated last. The order is runtime state. It is not written to layout JSON.

DockNode

A node in the dock tree. Either a SplitNode or a TabGroupNode.

DockPane

One piece of content in a layout. ContentId is the stable key an application uses to reconnect the pane to its control when a layout is restored. Ids are case-sensitive.

DockPaneClosingEventArgs

A pane that is about to close. Set Cancel to keep it where it is.

DockPaneEventArgs

A pane identified by ContentId.

DockPaneStateEventArgs

A pane moved between the main tree, a floating window, an auto-hide strip, and the hidden list.

DockPaneStates

Reads pane states from a DockLayout and diffs two snapshots. The WPF host uses this where it raises layout notifications. Panes that exist only in the later snapshot are new, not a state change. Panes missing from the later snapshot are reported as removed. A pane in Hidden is Hidden, not removed.

DockResizeMath

Grip thickness, splitter clamping, and floating-window edge tests. Sizes are device-independent pixels. The WPF host paints and applies the result.

DockSerializer

Compact versioned JSON. System.Text.Json source generation writes the tree directly, with no reflection and no extra package. Enums are lowercase strings and node kinds use a "type" discriminator ("split" or "tabs"). A document produced by Serialize(DockLayout) deserializes to an equal layout, including ids, weights, selection, floating bounds and maximized state, auto-hide entries, hidden panes, toolbar bands, and empty tab groups that a hidden entry names. An empty tab group with no such entry is rejected. ToolBars is omitted when it is null, so a document written before toolbars existed stays the same bytes. HideOnClose and a hidden entry's restore fields are omitted when they are the default, so a document with no hidden panes stays byte-for-byte the same. Unknown version numbers are rejected.

DockTabHeader

One tab header. The default template paints the dock palette. A host replaces the look with an implicit Style or a new Template. Drag, select, and close stay on this control. A template that omits a part has no such button.

DockTargets

Picks the dock window under a pointer. The topmost window that contains the point wins. The dragged window is skipped. No allocations.

DockTheme

Dock colors. The static brushes are the dark palette and stay the instances they have always been. Chrome, floats, guides, the switcher, and menus paint with resource keys, so Apply(FrameworkElement, DockThemeKind) can replace those brushes and open windows repaint. CreateMenuResources() is the opt-in menu and context menu. Nothing merges it on its own. CreateScrollBarResources() is the scrollbar, tooltip, and focus visual. The dock manager, each float, and the switcher merge it themselves. A host merges another copy for bars outside the dock.

DockToolBar

Attached properties for a ToolBar placed in ToolBars. A toolbar created from ToolBarsSource reads the same values from DockToolBarItem instead. KeyProperty identifies one button.

DockToolBarCaption

Caption of a floating toolbar. PART_Grip drags and double-clicks to dock. PART_Close hides the toolbar. PART_Title shows Title and trims it when the window is narrow. A trimmed title gets a tooltip with the full text. The close button stays a fixed width.

DockToolBarCustomize

Chevron that opens the Add or Remove Buttons menu. The default template strokes Dock.Text.

DockToolBarDrop

The line drawn while a toolbar is dragged over a band or an edge. The default template fills Dock.Accent. The control does not take the pointer.

DockToolBarGrip

The grip drawn at the leading edge of a toolbar. Drag it to move the toolbar. Leaving the tray undocks it into a floating window while the button is still held. Double-click docks a floating toolbar back to the band it left. The default template paints three dots with Dock.Muted on Dock.Chrome.

DockToolBarItem

Bindable properties for one toolbar in ToolBarsSource. A Style assigned to ToolBarItemStyle targets this type. Its setters bind against the item, which is the DataContext. The manager reads these values when the toolbar enters the source and again when they change. This element is not placed in the visual tree.

DockToolBarTray

One edge of the dock that hosts toolbar bands. The template's PART_Bands panel receives one child per band. The default template fills Dock.Chrome.

DockTree

Short constructors for a layout tree. The same tree can be built with object initializers or XAML.

DragPointer

Reused pointer state for DockDragSession. Fill Leaves and Headers in place so a drag move does not allocate those lists.

FloatWindow

A floating window. Coordinates are device-independent pixels.

HiddenEntry

A pane Hide(DockLayout, string) took out of the tree, plus the place Show(DockLayout, string) returns it to. Default place fields are omitted from JSON.

LayoutMap

Resolves a layout to content ids. Pass the ids the application can create and the map reports which saved panes have no factory (MissingContentIds) and which factories the layout does not use (UnplacedContentIds). Both of those lists are sorted. Panels follows the visible tree: main, then floating windows, then auto-hide edges. Hidden panes are not listed. A known id that is only hidden is not unplaced. An unknown hidden id is missing.

SplitChild

One cell of a SplitNode.

SplitNode

A resizable split. Proportions are positive weights, not required to sum to 1.

TabGroupNode

A tabbed group of panes. The selected index is part of the saved layout.

TabStrip

Header geometry for a tab strip, in the same coordinates as the pointer.

ToolBarBands

Hit testing and placement for toolbar bands. The host measures the trays and passes the rectangles. Hit(DockRect, string, ReadOnlySpan<ToolBarBarRect>, ReadOnlySpan<ToolBarBandRect>, ReadOnlySpan<ToolBarTrayRect>, double, double, string, string) does not allocate.

ToolBarCustomizationEventArgs

The toolbar and button a customization change refers to.

ToolBarDrag

Along-axis offsets that open a gap while a toolbar button is dragged.

ToolBarEntry

Where one toolbar sits. Edge, Band, Index, and Offset stay the last docked place while Floating is set, so a double-click can put it back. PaneId and WindowId name the pane or floating window that hosts it. Both null is the main window. Default values are omitted from JSON.

ToolBarItemEntry

One customized button. Key is the host's item key. HomeId is the toolbar whose collection owns the item; null means BarId. Items with no entry stay in collection order on their own toolbar.

ToolBarItems

Ordering and visibility overlay for toolbar buttons. The host collection is not modified. An item with no entry stays on its own toolbar. A new item is inserted after the nearest preceding collection neighbor that is still on that toolbar. Unknown keys are ignored.

ToolBarLayout

Toolbar bands and button customization stored with a DockLayout. Null on the layout, and omitted from JSON, when the host has no toolbar state. A document written before toolbars existed has no toolBars object and still loads.

WorkAreas

Places a floating window that lies entirely outside every monitor onto the nearest work area. A window that intersects any work area is left where it is. Coordinates are device-independent pixels, the same space as FloatWindow bounds.

AutoHideHit

An auto-hide drop. Preview is the strip, or the hot zone when the strip is collapsed.

AutoHideStrip

One auto-hide strip in the same coordinates as the pointer. Collapsed is an empty strip: the hit test uses HotZoneOf(DockRect, AutoHideEdge) instead of Bounds.

DockEditResult

Result of a layout edit. Refusals such as "cannot close" do not throw.

DockPaneStateChange

One pane whose DockPaneState differs between two layouts.

DockRect

A rectangle in the same coordinate space the host uses for pointer positions.

DockTarget

A window that can receive a dock drop. WindowId is empty for the main host. A larger ZOrder is painted above a smaller one. RootId is the node edge guides dock against.

DragStep

What a drag update did to the layout. Structure changes need a view rebuild; a follow only moves a window. TabsMoved means the dragged tab changed slots. The host redraws that strip and does not publish yet.

DropGuide

A dock target. Root-edge buttons dock against the whole host; other buttons dock against one leaf.

NodeBounds

Bounds of a leaf tab group, supplied by the view.

PaneLocation

Where a pane currently lives. Group is null for auto-hidden panes.

PlacedPanel

A pane located by Build(DockLayout, ISet<string>?) so a host can reattach content by ContentId.

ScreenDip

A point in device-independent pixels (1/96 inch), the units stored on a FloatWindow.

TabStrip.Header

One header along the strip. Index is the pane's index in its group. A negative index means this list is the whole group in order, and the list position is the model index.

TabStrip.Range

Contiguous headers that fit in a strip. First is the model index of the leftmost one. Overflow is true when at least one header is hidden.

ToolBarBandRect

Arranged bounds of one band. Bands on an edge are passed in band order.

ToolBarBarRect

Arranged bounds of one docked toolbar, in the same coordinates as the pointer. PaneId and WindowId are empty for a main-window tray.

ToolBarDrop

A drop target. Float tears the toolbar off. InsertBand opens a new band and shifts bands at Band and after it. Indicator is the line to draw.

ToolBarFloatMember

One toolbar inside a floating window, in the same coordinates as the pointer. Members of one window are visited in Index order by TryHitFloat(ReadOnlySpan<ToolBarFloatWindow>, ReadOnlySpan<ToolBarFloatMember>, string, string, double, double, out string, out int, out DockRect).

ToolBarFloatWindow

One floating toolbar window. Id is FloatId, or the toolbar id when the window holds one toolbar. A larger ZOrder is painted above a smaller one. Vertical stacks members top to bottom.

ToolBarItemRef

An item as the host collection currently holds it.

ToolBarPackItem

One toolbar to place in a band. Offset and Size are along the band.

ToolBarSite

One place a toolbar can dock. An empty PaneId and WindowId is the main window. A pane id is that pane's content. A window id is a floating window's id. A window with a larger ZOrder is painted above one with a smaller value. OwnerId is the window that shows a pane: empty for the main window, else a floating window's id.

ToolBarSlot

One slot in a toolbar after the customization overlay is applied. Hidden slots stay in the list.

ToolBarTrayRect

Arranged bounds of one edge tray.

Enums

Edge of the dock root that holds auto-hidden panes.

DockCaptionRole

Which caption this bar is. The default template hides the title row on a strip caption.

DockGesturePhase

Where a DockDragSession is in its gesture.

DockKind

Document panes live in the document well. Tool panes are tool windows and may auto-hide.

DockPaneState

Whether a pane is in the main tree, a floating window, an auto-hide strip, or hidden. The first three match PanelPlacement. Hidden is a pane kept in Hidden, which is not a placement the host shows.

DockResizeHit

Which edge of a floating window a pointer is on. None is the client area.

DockResizeMode

Whether a splitter, a flyout edge, or a floating window resizes during the drag or on release.

DockSide

Where a pane is docked relative to an anchor node.

DockThemeKind

Dark, light, or blue dock chrome. Dark is the default.

PanelPlacement

Where a pane sits after a layout is applied.

SplitOrientation

Children of a horizontal split sit left to right. A vertical split stacks them top to bottom.

TabPlacement

Which edge of a tab group draws the tab strip.

ToolBarAlignment

Which end of a band a toolbar packs against. Start is the left of a horizontal band and the top of a vertical one. End is the right of a horizontal band and the bottom of a vertical one. Start is the default and is omitted from JSON.

ToolBarCustomizationChange

What changed in a toolbar or in its buttons.

ToolBarEdge

Which edge of the dock hosts a toolbar band. A floating toolbar keeps the edge it left.
