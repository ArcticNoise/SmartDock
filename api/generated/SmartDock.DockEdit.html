Class DockEdit

Namespace

Mutates a DockLayout. Every successful structural edit leaves a layout that Validate(DockLayout) accepts. Empty groups are removed and single-child splits collapse, except an empty tab group that a hidden entry still names. That group stays, with its weight, as a restore anchor. Proportions are weights. A side dock gives the incoming pane the supplied proportion of the anchor's area.

CloseFloat(DockLayout, string)

Closes a floating window. Panes that can close are removed. Panes with HideOnClose are hidden, the same way the host close hides them. Panes that can neither close nor hide are docked into the main tree. The visible window goes away. A hidden pane keeps its empty group and these bounds so Show(DockLayout, string) can open that window again. The host does not show a window with no pane. A docked pane returns to PreviousGroupId when that tab group is still in the main tree. Otherwise it joins the first main-tree tab group of the same DockKind, or a new group on the right edge when the main tree has none.

Show(DockLayout, string)

Puts a hidden pane back and selects it in its group. The same tab group is used when it is still in the tree, including an empty restore anchor, at the saved index when that index still fits. Otherwise the same floating window is used, otherwise the same auto-hide edge. Otherwise the pane is docked with PreviousGroupId, then the first main-tree group of its DockKind, then a new group on the right. An empty group that no remaining hidden entry names is removed. Showing a pane that is already visible does not change the layout. An unknown id fails.
