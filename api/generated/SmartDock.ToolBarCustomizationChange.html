What changed in a toolbar or in its buttons.

public enum ToolBarCustomizationChange

Fields

Reorder = 0

A button was reordered inside its toolbar.

Move = 1

A button moved from one toolbar to another.

Hide = 2

A button was hidden.

Show = 3

A hidden button was shown.

Reset = 4

A toolbar's button customization was cleared.

ToolBarVisibility = 5

A toolbar was shown or hidden.

Created = 6

The user created a custom toolbar.

Renamed = 7

A custom toolbar was renamed.

Deleted = 8

A custom toolbar was deleted.

ItemCopied = 9

A button was copied onto a custom toolbar. The original stays on its own toolbar.

ItemRemoved = 10

A copied button was removed from a custom toolbar. The original is left as it was.
