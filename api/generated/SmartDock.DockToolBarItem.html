Class DockToolBarItem

Namespace
SmartDock
Assembly
SmartDock.dll

Bindable properties for one toolbar in ToolBarsSource. A Style assigned to ToolBarItemStyle targets this type. Its setters bind against the item, which is the DataContext. The manager reads these values when the toolbar enters the source and again when they change. This element is not placed in the visual tree.

Stable id used to save and restore this toolbar. Empty when the toolbar is added means the manager assigns an id for this stay. A saved layout finds the toolbar again only when this is the same value.

IsCustomizable

When true, Alt+drag and the Add or Remove Buttons menu can reorder and hide this toolbar's buttons. The default is true. ToolBarCustomizationEnabled also has to be true.

ShowOverflow

When true, the band gives this toolbar a finite length so its own overflow chevron can appear. The default is false, which measures the toolbar at its content size and leaves overflow to the host.
