Class DockTabHeader

Namespace
SmartDock
Assembly
SmartDock.dll

One tab header. The default template paints the dock palette. A host replaces the look with an implicit Style or a new Template. Drag, select, and close stay on this control. A template that omits a part has no such button.

[TemplatePart(Name = "PART_Close", Type = typeof(Button))]
[TemplatePart(Name = "PART_Pin", Type = typeof(Button))]
[TemplatePart(Name = "PART_Menu", Type = typeof(Button))]
[TemplatePart(Name = "PART_ButtonHost", Type = typeof(Panel))]
public sealed class DockTabHeader : Control, IAnimatable, ISupportInitialize, IFrameworkInputElement, IInputElement, IQueryAmbient
