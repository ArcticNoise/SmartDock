Where one toolbar sits. Edge, Band, Index, and Offset stay the last docked place while Floating is set, so a double-click can put it back. PaneId names the pane that hosts it. Both null is the main window. WindowId is an old floating-window edge; the dock moves that toolbar to the main window's top tray. Default values are omitted from JSON.

FloatVertical

True when the floating window stacks its buttons. The grip sits on top and the customize chevron at the bottom. Dragging the float's edge sets this from the window: at least as wide as it is tall is horizontal, including a square, and anything taller is vertical. A docked toolbar ignores this and takes its orientation from Edge. Docking, docking back, and reset clear it. A toolbar that is not floating drops it on load. Every toolbar in one floating window has the same value. Omitted from JSON when false, so a document written before vertical floats stays the same bytes.

Lines

Button lines in the toolbar's current orientation. A horizontal toolbar counts rows. A vertical toolbar counts columns. Zero is one line and is omitted from JSON, so a document written before line counts loads as one line and stays the same bytes. One is stored as zero. Docking onto an edge of the same orientation keeps the count. Docking onto the other orientation sets it to zero: the grid is not transposed. Reset sets it to zero. Undocking a count above one opens the same grid. Every toolbar in one floating window has the same value.

[JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingDefault)]
public int Lines { get; set; }
