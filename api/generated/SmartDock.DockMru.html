AdjacentDocument(DockLayout, string?, bool)

The next or previous document tab in tree order, wrapping across document groups. Tools, auto-hidden panes, and hidden panes are skipped. When activeContentId is not a document tab, next returns the first document and previous returns the last. Returns null when there is no other document tab.

Sync(List<string>, DockLayout?)

Drops ids that are not visible in layout and appends panes the order does not name. Hidden panes are left out. Appended panes follow the layout walk (main, floating windows, then auto-hide edges) and stay after recorded ones. A null layout clears the order.
